## Executive Verdict

Nomi has accumulated enough research to design a serious new language. It has
not lacked ideas; it has lacked the willingness to discard good local ideas
that weaken the language globally.

Before this consolidation, the active design/research surface occupied roughly
110 files and 74,000 Markdown lines across `language`, `features`,
`convenience`, and `research`. Several files independently claimed canonical or
active status. The result was not merely documentation duplication. It allowed
the language to hold incompatible intuitions at once:

- Python-like statements and expression-everywhere aspirations;
- one function model and five function spellings;
- one pattern model plus `if-let`, `guard-let`, `while-let`, and function
  clauses;
- one placeholder family described alongside two placeholder syntaxes;
- `where` for constraints, local definitions, and collection filtering;
- `->` for result types and caller-side block binding;
- `yield` as generator history, block-policy invocation, and a proposed basis
  for concurrency;
- explanation as a cross-cutting tooling property and as another core semantic
  normal form;
- runtime constraints without a settled package-scale static type contract;
- industrial ambition without one target package, effect, concurrency, or
  compatibility model.

The fresh decision is to optimize for **one recognition path per common
cognitive act**. Desugaring to a common core is necessary, but it is not enough.
Syntax is the user's front end to semantics, so its symbols and keywords must
have stable visual jobs.

The consolidated target is intentionally smaller and more opinionated:

```text
friendly inferred scripts
explicit typed public APIs
immutable bindings and data by default
nominal owned data, structural external values
one named function form and one explicit lambda
one match form
one collection vocabulary and one pipeline
Option / Result / panic as separate failure stories
exactly-once resource scopes
explicit effects and runtime capabilities
explicit async/await with structured child lifetime
structured diagnostics shared by every frontend
reproducible, content-addressed packages and builds
```

The current implementation will have to move toward this target rather than the
target being softened to match current code.

## Review Premises

1. There is no source-compatibility obligation before Nomi has a stable user
   base and release contract.
2. Existing behavior may be deleted even when implemented and tested.
3. Tests should be updated when the intended semantics change; they are not
   votes for old semantics.
4. The browser playground must continue to run supported snippets throughout
   migration.
5. Target-only examples remain outside `samples/` until parser, runtime,
   diagnostics, tests, and web execution agree.
6. Research is evidence. It does not receive permanent repository space merely
   because it was expensive to produce; Git history preserves the source.

## What Survived The Reset

The strongest prior ideas remain, but in a narrower form:

- cognitive friendliness and local reasoning are the product center;
- values, bindings, functions/calls, data, patterns, collection flow, world
  interaction, failure, and explanation recur across domains;
- nominal owned data and explicit decode boundaries are a high-value
  distinction;
- patterns and exhaustive matching are the natural elimination form for closed
  variants;
- absence, expected failure, and broken invariants need separate stories;
- source spans and structured diagnostics are architecture, not polish;
- pipelines help left-to-right reading when they mean only call insertion;
- resource lifetime should be lexical and deterministic;
- libraries and scoped tools should carry most domain sophistication;
- parser and backend artifacts must remain replaceable and conformance-driven;
- security, packages, formatter, LSP, and deployment belong in the language
  product, not a distant ecosystem afterthought.

## What Changed

### 1. Normal forms no longer justify unlimited sugar

The previous doctrine often said a form was safe if it reduced to an existing
normal form. That catches semantic invention but not recognition overload.

Nomi now asks a second question:

```text
Does this source form have a distinct visual job that a reader benefits from?
```

If not, the language keeps the canonical spelling. This removes equation and
piecewise functions, hole lambdas, operator sections, composition operators,
postfix conditionals, `unless`, local `where`, pattern-shortcut statements, and
collection verb aliases from the target.

### 2. Symbols now have narrow meaning families

The target establishes:

```text
_      pattern wildcard only
where  binding/data constraint only
->     function result type only
=>     explicit input or pattern maps to one expression
|>     first-argument call insertion only
?      Option/Result propagation only
?. ??  Option navigation/default only
with   exactly-once resource scope only
```

This is the main syntax-quality result of the review.

### 3. The type story is now package-scale

Runtime constraints alone are not enough for industrial library boundaries.
Fully mandatory annotations would damage the script/notebook experience.

The target therefore uses progressive static typing:

- infer direct local code;
- require explicit public package signatures;
- never infer `Any` as an escape;
- keep runtime constraints and decode checks;
- use nominal data for owned concepts;
- make structural uncertainty explicit as `Unknown` or `Value`.

This is a design target, not an implementation concession.

### 4. Binding now makes time visible

`name = value` creates an immutable binding. `var` and `set` mark state. `data`
is immutable. This is a more important cognitive simplification than preserving
Python reassignment behavior.

### 5. Universal block/yield control is rejected

Resource scope, retry, callback invocation, iteration, generators,
transactions, tracing, fixtures, and concurrency have overlapping shapes but
different temporal contracts. Treating them all as one caller-side block hides
whether code runs once, many times, concurrently, or after suspension.

The target splits them deliberately:

- `with` and `defer` for lexical cleanup;
- explicit function values for retry or multi-invocation policies;
- loops/collection APIs for repetition;
- reserved future generator design if needed;
- `async func`, `await`, and task groups for concurrency.

This gives up an elegant unification to preserve visible time.

### 6. Explanation becomes a pervasive contract, not a mini-language

Structured diagnostics and semantic events remain essential. `nomi explain`
is a tooling view over typed source, lowering, effects, plans, and execution.
The language does not need every trace or explanation operation to be a keyword
or a distinct semantic primitive.

### 7. Industrial scale is specified as contracts

The new industrial model names stable artifacts, effects/capabilities,
structured tasks, FFI, package identity, lockfiles, sandboxed builds,
content-addressed artifacts, editions, conformance, deployment, security, and
tooling. This prevents “industrial” from meaning a long list of domain syntax.

## Concrete Action Plan

### Phase A: Challenge The Target Before Implementing It

| Order | Action | Completion gate |
| --- | --- | --- |
| A1 | Format and manually review every section of `target.nomi`; remove any syntax that cannot be explained by the canonical docs. | Every punctuation form maps to one ledger entry; no accidental feature appears only in the demo. |
| A2 | Run focused syntax bake-offs for constraints, match arms, `uses`, async resource scope, and variant qualification. | Each experiment includes ordinary, beginner, and failure-heavy programs plus formatter and diagnostic sketches. |
| A3 | Write a compact grammar sketch and static-semantic rules from `syntax.md`, without looking at the current grammar. | An independent parser author can distinguish every accepted form and reject every removed ambiguity. |
| A4 | Turn the target demo into semantic conformance cases: binding, type, result, effect, output, diagnostic, and cancellation expectations. | The target has an executable specification independent of backend representation. |
| A5 | Have humans read the same 30-50 line task in target Nomi, Python, Rust, Kotlin, and one alternative Nomi syntax. | Record concrete comprehension errors; revise only from observed pressure. |

Do not begin broad implementation migration until A1-A4 agree. The language is
still cheap to change here.

### Phase B: Establish The Small Language

| Order | Action | Completion gate |
| --- | --- | --- |
| B1 | Define versioned lossless CST, Surface, typed Surface, and Core contracts for literals, binding, `func`, call, `if`, modules, and diagnostics. | Two parser frontends can produce equivalent Surface fixtures; one backend is not semantic authority. |
| B2 | Implement immutable bindings, `var`/`set`, lexical scope, and precise source diagnostics. | Creation and mutation have conformance tests across CLI and web. |
| B3 | Implement the progressive type boundary for inferred locals and explicit public signatures. | A multi-module package checks independently with no implicit `Any`. |
| B4 | Implement product/variant `data`, constructors, patterns, and exhaustive `match`. | Domain values cannot enter invalid states; every closed match is checked. |
| B5 | Implement `Option`, `Result`, and postfix `?`; remove convenience forms that compete with them. | Absence, expected failure, and panic have distinct types, diagnostics, and tests. |
| B6 | Implement strict `Value -> decode -> data` with accumulated path errors, explicit coercion, defaults, provenance, and redaction. | One useful config/record import is easier to diagnose than its Python equivalent. |
| B7 | Implement loops, the canonical collection verb family, `Stream`, and call-only `|>`. | Eager/lazy/materialized behavior is visible and backend-consistent. |

### Phase C: Make It Useful In The World

| Order | Action | Completion gate |
| --- | --- | --- |
| C1 | Ship a minimal prelude and explicit console, text, JSON, CSV, path, file, time, process, and HTTP modules. | A boring import-transform-report program needs no host-language escape. |
| C2 | Implement `uses` checking and runtime capabilities for console, files, clock, random, process, network, and database hosts. | Tests substitute every world source; browsers reject unsupported authority before execution. |
| C3 | Implement exactly-once `with`, `defer`, cause groups, and async cleanup. | Return, propagation, panic, cancellation, and double-failure fixtures all clean up deterministically. |
| C4 | Implement `async func`, `await`, task groups, cancellation, deadlines, and multi-error policy. | No child task leaks from a group; failure behavior is identical across supported runtimes. |
| C5 | Promote the target workflow in small slices to runnable `samples/` only as each slice gains parser/runtime/web coverage. | The web playground never advertises target-only syntax as runnable. |

### Phase D: Industrialize The Language

| Order | Action | Completion gate |
| --- | --- | --- |
| D1 | Deliver canonical formatter, language server, REPL, notebook, browser, doc generator, and shared diagnostic renderer. | All surfaces consume the same typed artifacts and result records. |
| D2 | Deliver `nomi.toml`, exact `nomi.lock`, pure dependency fetch, signatures, sandboxed deterministic builds, and content-addressed artifacts. | Clean machines reproduce byte-identical outputs from declared inputs. |
| D3 | Define portable FFI/interface contracts and native/Wasm profiles. | Foreign ownership, errors, blocking, effects, and representation are explicit and tested. |
| D4 | Establish differential conformance, fuzzing, performance envelopes, security auditing, and release provenance. | Every supported frontend/backend publishes evidence by capability axis. |
| D5 | Introduce edition/migration machinery only after the first stable release candidate. | One real breaking migration is automated and semantically checked. |

### Phase E: Earn Advanced Domains

Only after the earlier phases should Nomi prototype table query notation,
multiple dispatch, units, tensor/rank features, symbolic quotation, generators,
actors, or macros. Each begins as a library or scoped experiment and must
improve the target program without weakening ordinary syntax.

## Acceptance For This Pass

This review pass is complete when:

- one compact design set has explicit authority;
- the research corpus is consolidated into evidence, convergence, and open
  experiment documents;
- duplicate active design/research files are removed;
- the target demo uses the same syntax and semantics as the canonical docs;
- repository navigation and agent instructions point only at live files;
- Markdown lifecycle/inventory checks pass;
- the current full test suite still passes or is deliberately updated;
- the web manifest/runtime contract still passes.

The next hard problem is not more synthesis. It is trying to break the target
syntax with concrete programs before implementation makes it expensive again.
