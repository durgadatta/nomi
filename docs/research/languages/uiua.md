# Uiua

> Status: comparative evidence; mechanisms scoped to the historical 0.11 article.

## Observe

Uiua's array-oriented, tacit model uses stack manipulation and higher-order
array operations. Its 0.11 announcement also describes a browser pad used to
inspect examples; it is not evidence of today's exact feature inventory.
[Primary reference: 0.11 announcement](https://www.uiua.org/blog/uiua-0.11.0-html.html).

## Judge And Pay

**Adopt** rapid visible feedback and inspectable intermediate state. **Reject**
implicit stack argument flow as Nomi's default recognition path. **Defer** tacit
array notation to a bounded domain experiment.

Explicit names consume space and can interrupt an expert's flow. Nomi's
playground should compensate with useful value/type/reduction inspection, not
additional hidden syntax. Uiua shows why a live pad is part of language design:
a notation can be learned through observed state rather than prose alone.

## Test

Build a proposed playground view of the named intermediates in
[collections](../../design/targets/collections.nomi). Require stable types,

with and without this view; do not claim a learning advantage before evidence.
