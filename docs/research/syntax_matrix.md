# Syntax Matrix: The Forms People Read And Write

> Status: syntax evidence and Nomi judgments; illustrative fragments, not executable conformance.

This language-row table accompanies the [semantic transpose](feature_language_matrix.md)
and [feature-row view](language_feature_matrix.md). It covers the same 45
languages and two interfaces, with a **Nomi target row** for direct comparison.
Each feature cell shows representative **actual spellings**, not just semantic
labels. The [form study](syntax_forms.md) expands alternative forms, punctuation
collisions, complete layouts and the costs of Nomi's corresponding long forms.

For greater domain depth rather than more sparse columns, see
[data source forms](data_workflows/source_forms.md),
[workflow forms and execution](data_workflows/execution_models.md), and
[cross-disciplinary notation](notation_atlas.md). Their literal forms expose
context, staging, axes and identity; they are research, not extra accepted Nomi forms.

## Scope And Reading

- `...` stands for omitted source, not a claim that every language accepts an
  ellipsis token there. `<br>` separates fragments; it does not encode indentation.
- Identifiers such as `xs`, `p`, `f`, and `ready` assume suitable declarations.
  Fragments in different cells are not one program and are not semantic equivalents.
- A header, type spelling, macro fragment or library call is not necessarily a
  standalone executable. No foreign compiler or Nomi typechecker ran this atlas.
- `-` means **not compared in this syntax pass**, not unavailable. An explanatory
  cell without code distinguishes a library/protocol concern from dedicated syntax.
- Primary references were consulted on 2026-09-30; the Mojo row was added from
  official documentation labelled 1.1.0 on 2026-10-10. These are representative
  excerpts of grammar, not an exhaustive inventory of extensions or versions.
  C is C11; Scala is Scala 3; SQL is PostgreSQL; HCL is Terraform; APL is Dyalog;
  Uiua is the historical 0.11 article. Roc uses the **new compiler tutorial**,
  not alpha4. Other living docs are not pinned conformance standards.
- Foreign glyphs are retained deliberately. Judge argument visibility, role,
  copy/edit behavior and diagnostics, not ASCII versus Unicode in isolation.
- The Nomi row mixes accepted **source forms** with explicitly proposed library
  names. Its type/codec/effect/task guarantees remain subject to their design gates.

## Interpretation

These are Nomi design judgments, not usability rankings. More tokens can
clarify a boundary or merely add ceremony; fewer tokens can expose algebra
or conceal a call/exit/capture. Neither result is established by this table.
Use the beginner, production and failure-heavy comparisons in
[the form study](syntax_forms.md), then record any changed decision in
[canonical syntax](../design/syntax.md) and [the ledger](../design/decisions.md).
Do not promote a foreign spelling or a hypothetical library API by copying it
into a runnable sample.
