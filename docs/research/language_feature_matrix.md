# Language-Feature Synthesis Matrix

> Status: compact comparative evidence and Nomi design judgments; not specification or conformance.

One table crosses all **13 feature reviews** with all **44 language reviews**,
plus **Excel and keyboard commands** from the broader interface research.
Languages follow the family order in [the language index](languages/README.md);
the last two columns are human-computer interfaces, not conventional languages.

Read a cell as **documented mechanism -> Nomi implication**. The row and column
margins link to the corresponding detailed reviews, which own primary citations,
version limits, costs, and experiments. **`-` means no useful finding summarized
for that intersection in the existing review, not that the language lacks the
feature.** This is intentionally sparse, not an exhaustive feature inventory.

The Nomi ambition column routes to targets/proposals; it is not a claim that
their syntax, APIs, or static guarantees are all accepted or implemented.
[The synthesis](../design/synthesis.md) and
[design-first agenda](../design/redesign_agenda.md) own cross-feature coherence
and ordering. This matrix adds no decisions, competing backlog, or new research
claims. The other [interface threads](interfaces/README.md) remain separate
evidence; they have not been folded into unsupported language feature claims.

This is deliberately a wide Markdown table. In the VS Code Markdown preview
or GitHub rendered view, use horizontal scrolling to compare columns; the
linked feature pages remain the narrower reading route.
