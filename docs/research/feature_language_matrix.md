# Feature-Language Synthesis Matrix (Transposed)

> Status: equivalent transposed evidence view; not specification or conformance.

This is the exact transpose of [the feature-row matrix](language_feature_matrix.md):
**one language/interface per row, one feature per column**. The Nomi ambition
column becomes the first body row. Every language/interface intersection retains the original wording and links.
Change the original matrix and its transpose together; a focused test checks
cell-for-cell equivalence so these views do not become competing evidence.

Read a cell as **mechanism -> Nomi implication**. `-` means no useful finding
summarized, not an absent capability. Margins link to the detailed reviews;
their primary references, version limits and evidence qualifications still apply.
For actual spelling, layout and alternative forms, use the
[syntax matrix](syntax_matrix.md) and [syntax form study](syntax_forms.md).
