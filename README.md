# Nomi
**Nomi: A Minimal, Systematic, and Intuitive Programming Language**

Nomi is an experimental programming language built on a minimal core of variables, function definitions, and function applications. Drawing inspiration from functional programming, it prioritizes **clarity, consistency, and human-centered reasoning**, creating a simple yet expressive system.

Its philosophy avoids feature overload, focusing on a **coherent framework**. By reducing primitives while preserving expressiveness, Nomi encourages a disciplined and intuitive approach to coding that aligns with how humans think about processes and abstractions.

## Vision and Motivation

With extensive experience in **Python** across academic, startup, and corporate settings, and exploration of languages like **C, Java, JavaScript, Scala, Julia, Lisp/Scheme, Haskell, Mathematica, and APL**, I have come to see programming as the **backbone of modern IT**. Programming integrates computation, data, communication, and technology into a unified framework.  

Modern programming spans diverse domains — **frontend, backend, data science, systems programming, shell scripting, scientific computing, AI, configuration management, documentation generation, testing, deployment, embedded systems, mobile apps, game development, cloud computing, blockchain, networking, security, DevOps, IoT, robotics, and virtual reality**. Each brings its own **languages, tools, conventions, paradigms, and mindsets**, which often leads to fragmentation. Nomi challenges the idea that such differences are inevitable. By building a **common, coherent core** inspired by **Lambda Calculus** and **guided by human cognition**, Nomi allows **domain-specific adaptations and extensions** to emerge naturally from minimal primitives, unifying control flow, type systems, libraries, error handling, concurrency models, and more, while maintaining **simplicity, coherence, and expressiveness**.


## Historical and Personal Context

My fascination with programming languages began with **C** in undergraduate projects, but it was **Python** that sparked my curiosity about language design. Encountering **Tcl** deepened this interest, shifting my focus to how languages are crafted rather than just used. In 2015, I shared early reflections in a [blog post](https://dindefi.wordpress.com/2015/09/08/programming-languages-pl/) (no longer maintained). Over the years, I collected ideas that remained scattered.  

**Nomi is the culmination of a decade of exploration**, transforming my passion into a concrete, systematic, and human-focused programming language.
