# nomi
Nomi: A Minimal and Systematic Language

Nomi is an experimental programming language that starts with a very small core — variables, function definitions, and function applications — and builds everything else from there.

The goal is not to pack in features, but to make the essentials clear, consistent, and easy to reason about. By reducing the number of primitives while keeping the language expressive, Nomi encourages a more systematic way of thinking about code.

# Historial and Personal Context
My deeper interest (beyond the techincal usage of C in undergraudate projects) in programming languages began with Python, which first got me thinking about how languages work. That fascination deepened when I later encountered Tcl, where I became even more intrigued by the design itself, not just usage.

A few weeks after that experience, I left my job and wrote down some early reflections in this [blog](https://dindefi.wordpress.com/2015/09/08/programming-languages-pl/) in 2015 (not actively maintained). Since then, I’ve occasionally collected notes and ideas, but never fully realized them — Nomi is my attempt to give those ideas a concrete form.
